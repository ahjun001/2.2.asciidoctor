= adoc basics & exercises
Learning by doing, leaving a trace for when it got old

== Scope & purpose
This document aims at growing, step-by-step, the ability to write in adoc without reading the reference.

It is also a testing ground for what works and renders well on the present settings.

== Howto learn code commands
Writing a cheatsheet, writing `code` -- explanations

`ping -c 4 google.com` -- Test the connectivity between this machine and Google servers `-c 4` limits the test to 4 packets

`wc [file]` - Count lines, words, bytes

* `wc -l` - Prints the number of lines in file
* `wc -w` - Prints the number of words in file
* `wc -m` - Prints the count of characters

== Performing the full process once

* `asciidoctor -b html5 __filename__.adoc` -- creates __filename__.html
* `asciidoctor-pdf __filename.__adoc` -- creates __filename__.pdf
